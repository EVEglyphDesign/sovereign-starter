Sovereign Starter · v1.0

The most basic boundary
you can put around an AI surface.

Three edges. One repository. Downloadable as one Markdown file — but the lesson is not the download. The lesson is the handshake that puts the file in place. Ask your AI surface to do it. GitHub is where the pattern is safe to practise.

See the three-step handshake See the repository

Three vertices on the repository boundary: Boot contract, Canon, Sin registry. The triangle is inscribed in the circle — each vertex is an intersection with the boundary, not a floating point inside it.

The three edges

1. Boot contract

How the AI surface behaves before it does anything. The read-first rule. The one edge every session starts on.

2. Canon

How the artifact leaves the repository. The output shape. The edge the work travels along on the way out.

3. Sin registry

How the truth of what happened is preserved. The record of what was done wrong so it can be done right. The edge that closes the triangle.

Take the boot contract away and the surface drifts. Take the canon away and the artifact leaks. Take the sin registry away and the other two become preferences instead of rules.

Why bother

The AI surface is a web browser. Nothing you say to it is permanent. Nothing you reason inside it comes back to you once the session closes.

Facebook is beginning to give people their history back. AI surfaces are not promising that yet. Until they do, the only way to keep what you think is to keep it somewhere you hold. You hold the repository. That is the whole idea. Everything else is mechanics.

This scaffold is not the sophisticated version. It is not the enterprise version. It is not the controlled EVEglyphDesign canon. It is the minimum shape that still works. More guardrails can be added on top later. The three edges are the floor.

Use it

The three-step handshake — recommended

You do not download the file. You ask your AI surface to place it. That is the whole lesson. GitHub is the training platform because it is built to let you leave; the same handshake unlocks the surfaces that are not. X marks the spot on every screen.

Say this to your surface first, verbatim:

Connect my GitHub account. When you cannot do that from inside this chat, hand me off — send me the exact link and tell me exactly what to click. When I am back and connected, create a new public GitHub repo named sovereign-starter, fetch SOVEREIGN-STARTER.md from EVEglyphDesign/sovereign-starter, commit it into the new repo as README.md, then read it and follow §0.

The surface will now walk you through three screens. All three look like this on every AI surface — Perplexity, Claude, ChatGPT, Gemini — because the last two are GitHub's own screens, not the surface's.

1. If you have no GitHub account yet, the surface sends you to github.com/signup. Register. Come back.
2. The surface hands you to GitHub's authorize screen. Sign in, then Authorize. This screen is GitHub's, not the surface's — the same screen every surface uses.
3. You land back in the surface. GitHub reads Connected. Paste the prompt again if it lost it. The surface creates the repo and drops the file. You now own the boundary.

You just watched the pattern that unlocks every other platform. Ask the surface. Get handed off to register. Come back and let the surface write. On GitHub the handoff is thirty seconds. On the surfaces built to trap you it will fight harder — but the shape of the move is the same. This is how you take screenshots of your own lock-in and walk out of it.

Manual fallback — if you already live on GitHub

If you already have a GitHub account, a terminal, and no interest in the handshake, skip it:

  1. Download SOVEREIGN-STARTER.md.
  2. Save it as README.md in the root of a new GitHub repository you control.
  3. Open your AI surface and point it at the file. Read §0.
  4. Prefer a whole scaffold? Clone the repository as a template — you get docs/BOOT-CONTRACT-STARTER.md, registry/DEFECTS.md, and this landing page. Rename, edit, push.
